# 客户端守护脚本

每 3 分钟由 launchd 自动运行，客户端异常时自动恢复，结果推送到群机器人通知。
**本仓库只含通用脚本，不含任何凭证。**

## 能力
- **进程掉线 / 假活** → 自动退出重开（客户端静默重连）
- **登录态失效**（登出 / 槽位到期）→ 接口直登恢复，零 GUI 零权限
- **结果通知**：异常 / 恢复 / 部署，全程不用盯
- **自更新**：发布新版本后，已部署的机器 3 分钟内自动升级

## 安装
一条命令（通知渠道凭证、登录密钥，按安装包说明填进各自机器的 `config.sh`）。

## 自更新机制
- 机器上 `config.sh` 配 `AUTO_UPDATE_URL` 指向本仓库 `guard.sh`
- 每轮顺带比对 `VERSION`，不一致则下载 → 校验 → 替换 → 重启守护
- 下载失败 / 校验不过 → 保持旧版，下轮再试（绝不安装损坏文件）
